Update Opensuse Tumbelweed via terminal after install.

sudo zypper ref -b && sudo zypper dup

-----------------------------------------------------

Install this programs - good for you =)

sudo zypper install bash git npm wget curl nano sudo dialog go dracut opi nano gnome-terminal yast

-----------------------------------------------------

Add extra Mirrors and install codecs for OPENSUSE TUMBELWEED.

sudo zypper ar -cfp 90 https://ftp.gwdg.de/pub/linux/misc/packman/suse/openSUSE_Tumbleweed/ packman

sudo zypper dup --from packman --allow-vendor-change  <-- press a in terminal

Copy and paste in terminal: opi codecs

-----------------------------------------------------

Install Fastfetch and Test from terminal.

sudo zypper in fastfetch

Type Fastfetch in terminal to test: fastfetch

-----------------------------------------------------

Install Google-Chrome

sudo zypper install opi*

opi google-chrome

-----------------------------------------------------

Install GIMP

sudo zypper in gimp

Fix IP problem X410. Cant find screen problems. Look ip adress in windows terminal / PowerShell: ipconfig

NOTE: open Powershell and type: ipconfig - Last lines is WSL ip.

EXTRA: Save ip here for WSL: 172.30.16.1

Type this in Opensuse Terminal.

sudo zypper in systemd-resolved

sudo ls -l /etc/resolv.conf

sudo mv /etc/resolv.conf /tmp/resolv.conf.bak

sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from powershell and add nameserver.

sudo chattr +i /etc/resolv.conf

sudo systemctl restart systemd-resolved

sudo cat /etc/resolv.conf

DONE - alot of problem fixed =] If you see some RED text dont worry it works any way.

export XDG_SESSION_TYPE=x11
