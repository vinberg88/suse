Update OpenSUSE LEAP 16 via terminal.

sudo zypper refresh
sudo zypper update

----------------------------------------------------------------------

Install this programs for OpenSUSE LEAP 16 - 2026 - KDE 6

sudo zypper install bash git npm wget curl nano dialog go opi sddm gnome-terminal yast2

----------------------------------------------------------------------

Install all - one by one - OpenSUSE LEAP 16 Packman.

sudo zypper ar -cfp 90 'https://ftp.gwdg.de/pub/linux/misc/packman/suse/openSUSE_Leap_$releasever/' packman

sudo zypper dup --from packman --allow-vendor-change

opi codecs

Fix IP problem for X410. Cant find screen problem.

OPEN POWERSHELL AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL.

SAVE IP HERE FROM POWERSHELL: 172.30.16.1

GO BACK TO OpenSUSE LEAP 16 AND COPY AND PASTE THIS IN TERMINAL.

sudo zypper install dbus-1-daemon

sudo zypper in systemd-resolved

sudo ls -l /etc/resolv.conf

sudo mv /etc/resolv.conf /tmp/resolv.conf.bak

sudo nano /etc/resolv.conf

nameserver 172.30.16.1  <-- put your ip here from powershell and add nameserver.

sudo chattr +i /etc/resolv.conf

sudo systemctl restart systemd-resolved

sudo cat /etc/resolv.conf
